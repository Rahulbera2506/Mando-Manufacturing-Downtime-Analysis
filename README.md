# Mando Manufacturing Company – Downtime & Production Loss Analysis

## Project Overview

This project focuses on analyzing manufacturing downtime and production loss using Power BI.

The goal is to understand machine downtime, identify major downtime reasons, and analyze their impact on production loss.

## Business Questions

- Which machine has the highest downtime?
- Which downtime reason occurs most frequently?
- Which reason causes the highest production loss?
- Which machines have the most breakdown incidents?
- How does downtime affect production loss?

## Tools Used

- Power BI
- Power Query
- SQL

## Key Analysis

- Total Downtime Hours
- Total Incidents
- Production Loss
- Machine-wise Downtime
- Downtime by Reason
- Production Loss by Machine
- Production Loss by Reason
